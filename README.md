### 📉 Employee Churn Prediction System

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-FF6F00?style=flat-square&logo=scikitlearn&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white)

- 🧹 Data preprocessing, feature engineering and model training on historical employee data

- 💡 Gives insights that support employee retention and workforce management decisions
